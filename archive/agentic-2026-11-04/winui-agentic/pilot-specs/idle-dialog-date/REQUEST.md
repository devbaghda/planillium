# Feature request: date in the "Welcome back" absence dialog

User request (2026-10-01): "In the message for logging the absence I want to have the date as well.
Now it shows only the time and the minutes of absence."

Today the dialog reads e.g. "You were away 6 min (10:30–10:36). What was it, roughly?". Add the
calendar date of the absence to that sentence. An absence that crosses midnight must make that
clear (both dates, or an unambiguous equivalent). Use the app's existing date-display conventions.
