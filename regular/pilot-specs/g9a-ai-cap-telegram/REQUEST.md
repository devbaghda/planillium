# Request -- G9a AI monthly cap + Telegram by chat name (user, 2026-10-29; DECISIONS rule 19 e, f)

1. AI monthly cost cap. The app limits what the AI features (Ask Claude, anything that calls the AI) may cost in a
   calendar month. Default EUR 5, editable in Settings. When the month's spend reaches the cap, AI features stop
   with a clear message that says the cap was reached, the amount spent and where to raise it; nothing is lost, and
   non-AI features are unaffected. A new month starts at zero. The user sees the month's spend and the cap in Settings.
2. Telegram by chat name. In the time diary, Telegram activity is told apart by the chat name shown in the window
   title (not by person, number or anything else). The chat name is available wherever a diary row's app/description
   is used for rules, search and the filters (it is the same text the user already sees). No rule learning yet.
Not to change: any other behaviour; scoring; the working-hours rule.
